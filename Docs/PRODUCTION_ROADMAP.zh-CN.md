# 3DPlayDemo 制作计划

更新时间：2026-08-11

## 当前验收结果

- 原型渲染管线保持不变，只补回缺失的 URP 资源引用，洋红材质显示问题已修复。
- 已可玩流程：第 1 训练区 → 第 2 断电回廊 → 战地商店 → 核心熔炉 Boss。
- 已接通：敌人变体、金币、击杀奖励、场景战利品、通关奖励、下一关按钮、装备购买、自动装备、36 格背包。
- HUD 已通过运行截图复核：金币位于左上生命条下方，仓库和装备位于右上，无遮挡。
- 战斗打磨已加入：敌人伤害数字、元素颜色、命中粒子和 Boss 专属血条；运行时无新增错误日志。
- 成长闭环已加入 Run JSON 存档；Boss 已加入两道阶段阈值和三阶段攻击/材质变化。
- 测试：EditMode 204/204，PlayMode 7/7。

## 设计方向

1. 关卡：每关由战斗区、奖励区和出口组成，关卡定义负责敌人、奖励和下一关，不把流程写死在场景脚本里。
2. 成长：金币用于商店购买，装备沿用现有属性、套装和 Buff 计算；后续增加词条、稀有度和装备主动效果。
3. 战斗：基础敌人负责压迫，精英敌人负责改变站位，Boss 使用阶段、范围攻击和可读的前摇制造交互。
4. 内容：优先复用项目已有模型和材质，外部素材只在授权清晰且能直接提升关卡表现时引入。

## 后续制作顺序

- 存档：保存金币、解锁节点、背包、装备和已领取奖励。
- 存档深化：增加版本迁移、坏档备份和多存档槽位。
- 商店：加入刷新库存、稀有度颜色、价格曲线和购买反馈。
- 战斗：加入受击闪白、命中特效、连击窗口和精英技能；Boss 三阶段继续补专属技能和场地机制。
- 关卡：为第 2 关和 Boss 关补充更明确的路径、掩体、奖励房和出口演出。
- 内容：增加远程敌人、护盾敌人、召唤敌人及至少两套独立外观。
- 打磨：音效、环境音、伤害数字、性能检查、首次运行检查和构建验证。

## 约束

- 不修改全局渲染管线，不把项目迁移到 Built-in/HDRP。
- 任何 UI 改动都要以运行截图检查实际遮挡、缺字和分辨率适配。
- 每轮改动后先看 Unity Console，再跑 EditMode/PlayMode 测试，最后再提交。

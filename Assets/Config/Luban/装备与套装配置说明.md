# 装备与构筑配置说明

装备、套装、装备效果和掉落候选使用 Luban 表格；关卡场景与关卡奖励仍由 Unity 的 ScriptableObject 管理。敌人类型与唯一预制体的对应关系由 `enemy_archetypes.csv` 统一维护。

## 四套推荐构筑

| 构筑 | 核心打法 | 2 件 | 4 件 | 5 件 |
| --- | --- | --- | --- | --- |
| 炽焰连击 `ember_combo` | 命中叠燃烧，贴身连续攻击 | 攻击 +8 | 攻击 +15% | 暴击率 +8% |
| 潮汐续航 `tide_sustain` | 施加潮湿，闪避和攻击维持生命 | 最大生命 +50 | 防御 +15% | 最大生命 +20% |
| 疾风机动 `gale_mobility` | 风痕叠层，依靠闪避和追击输出 | 攻击 +6 | 暴击率 +10% | 攻击 +18% |
| 震岳破防 `seismic_breaker` | 叠破碎，靠重击创造破防窗口 | 防御 +10 | 攻击 +12% | 暴击伤害 +25% |

每套固定包含武器、护甲、鞋子、头盔和饰品五件。装备成员关系见 `equipment_set_members.csv`，件数奖励见 `equipment_set_bonuses.csv`。百分比数值使用小数表达，例如 `0.15` 表示 15%。

## 表格职责

- `equipment.csv`：装备基础属性、槽位、品质和图标。
- `items.csv`：背包展示名称、分类、品质、堆叠上限和玩家可读描述；四套装备描述使用 `【构筑名】` 开头。
- `equipment_effects.csv`：元素、触发时机、Buff、持续时间、层数和冷却。
- `equipment_sets.csv`：套装稳定 ID 与中文名。
- `equipment_set_members.csv`：装备 ID 到套装 ID 的唯一归属。
- `equipment_set_bonuses.csv`：2/4/5 件奖励的属性词条。

修改后，在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\GenerateLubanConfig.ps1
```

脚本会同时更新生成的 C# 表类和 `Assets/StreamingAssets/Config/LubanBytes` 二进制表。回到 Unity 后等待编译，再运行相关测试。

## 敌人掉落规则

`BuildLootResolver` 根据敌人原型和稳定实例 ID 进行确定性选择，不使用全局随机状态：

- 普通敌人有较低概率掉落其对应构筑装备，否则掉落构筑相关消耗品或升级材料。
- 精英敌人的构筑装备概率更高。
- Boss 必定掉落对应构筑的高品质装备；只有目录缺失时才使用升级材料兜底。
- 装备候选从运行时 `EquipmentItemDefinition.SetId` 和背包目录交集派生，掉落 ID 必须是合法背包物品。
- 未登记的新敌人原型不会静默偏向某一套，而是按原型 ID 稳定轮转到四套构筑之一；正式加入原型表后应补充明确映射。

商店继续读取背包运行时全目录，因此四套构筑装备和已有物品都可以购买。

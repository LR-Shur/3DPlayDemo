# 装备与套装配置说明

本项目的职责边界如下：

- 关卡配置继续使用 `Assets/Data/Levels/*.asset`（ScriptableObject）。场景点位预制体和关卡 SO 方便在 Unity 编辑器中拖拽、调整，不迁移到 Luban。
- 装备、装备效果、套装、套装成员、套装效果使用 Luban 表格。运行时由 `LubanConfigService` 读取生成的二进制表，再转换成 Equipment/Inventory 领域对象。

## 修改装备

使用 UTF-8 编码编辑：

- `equipment.csv`：装备基础属性、槽位、稀有度、图标地址。
- `equipment_effects.csv`：元素、触发时机、Buff、持续时间、层数和冷却。

装备的 `id` 必须唯一；`equipment_effects.csv` 中的 `equipment_id` 必须对应装备表中的 `id`。

## 修改套装

- `equipment_sets.csv`：套装 ID 和中文名称。
- `equipment_set_members.csv`：装备 ID 与套装 ID 的归属关系。
- `equipment_set_bonuses.csv`：套装达到几件时生效，以及属性、运算方式和数值。

套装成员表中的同一个装备只应出现一次。套装效果的 `required_piece_count` 可以配置为 2、4 等；同一套装和件数的多行会合并为同一档效果。

## 生成与运行

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\GenerateLubanConfig.ps1
```

脚本会生成 C# 表类和 `Assets/StreamingAssets/Config/LubanBytes` 下的二进制表。回到 Unity 后等待编译，再运行场景即可。

如果修改的是 YooAsset 收集路径或地址规则，在 Unity 菜单执行一次：

`Tools/Train/Architecture/Configure YooAsset`

运行时代码只使用地址（例如 `Levels_Level_Combat_001`、`Player_Player_Ellen`），不依赖项目磁盘绝对路径。

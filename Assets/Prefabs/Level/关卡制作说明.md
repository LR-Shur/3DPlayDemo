# 新增关卡制作

## 场景

1. 新建一个场景并摆好地图、灯光和碰撞体。
2. 把 `Assets/Prefabs/Level/LevelRuntimeRoot.prefab` 拖入场景。
3. 创建 `Train/Game Flow/Level Definition`，填写关卡 SO。
4. 将 SO 拖到 `LevelRuntimeRoot` 上 `Level Runtime Controller` 的 `Definition` 字段。
5. 在 SO 里填写场景路径、玩家出生位置、敌人生成列表和奖励。
6. 直接测试时勾选 `Auto Start`；需要训练终端或剧情触发时保持关闭。

玩家和敌人的运行时实例都由 SO 和 YooAsset 生成，不需要提前把玩家或敌人预制体拖进场景。场景里的 `PlayerSpawnPoint` 只用于旧场景兼容，新的关卡优先使用 SO 的 `Player Spawn Position` 和 `Player Spawn Euler Angles`。

## 当前下一关规则

当前版本的顺序仍由 `ProgressionService` 中的 `RunNode` 列表维护：第一关、第二关、Boss 关按列表顺序推进。通关后 `ProgressionRuntimeController` 读取下一个 `RunNode.ScenePath`，加载对应场景；场景里的 `LevelRuntimeRoot` 再使用自己绑定的关卡 SO。

因此新增关卡目前需要两步：创建并绑定新的关卡 SO，以及在 `ProgressionService` 的 `_nodes` 列表加入一个 `RunNode`。后续可以再把这份流程节点列表也迁移成 SO，做到完全数据驱动。

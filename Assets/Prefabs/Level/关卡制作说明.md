# 新增关卡制作

## 场景

1. 新建一个场景并摆好地图、灯光和碰撞体。
2. 把 `Assets/Prefabs/Level/LevelRuntimeRoot.prefab` 拖入场景。
3. 创建 `Train/Game Flow/Level Definition`，填写关卡 SO。
4. 将 SO 拖到 `LevelRuntimeRoot` 上 `Level Runtime Controller` 的 `Definition` 字段。
5. 在 SO 里填写场景路径、玩家出生位置、敌人原型、生成位置和奖励。
6. 直接测试时勾选 `Auto Start`；需要训练终端或剧情触发时保持关闭。
7. 场景必须包含已构建的 `NavMeshSurface`；保存前确认导航网格覆盖玩家与敌人的主要战斗区域。

玩家和敌人的运行时实例都由 SO 和 YooAsset 生成，不需要提前把玩家或敌人预制体拖进场景。玩家出生位置优先使用 SO 的 `Player Spawn Position` 和 `Player Spawn Euler Angles`。

敌人点位支持两种方式：

- 想纯数据配置时，直接编辑关卡 SO 中敌人条目的 `Position` 和 `Euler Angles`。
- 想在场景里拖拽时，拖入 `Assets/Prefabs/Level/EnemySpawnPoint.prefab`，设置 `Spawn Id`，然后在场景中移动和旋转它。运行时会优先读取同名点位的 Transform；没有匹配点位时才回退到 SO 数值。

每种敌人只在 `Assets/Config/Luban/Data/enemy_archetypes.csv` 指定一个 canonical 预制体。关卡点位只选择 `ArchetypeId`，同步工具会自动写入对应预制体引用；不要为了单个关卡复制或缩放敌人预制体。

编辑器菜单 `Tools/Train/Level Design/Sync Current Scene To Level Definition` 会把场景点位的 Transform、敌人原型和 canonical 预制体路径同步回 SO。场景点位少于已有 SO 编制时，同步器会保留未匹配条目，避免误删整关敌人。

`Tools/Train/Level Design/Normalize All Enemy Archetypes` 用于检查全部关卡的原型与预制体对应关系，并移除场景内不该静态存在的敌人副本。`Tools/Train/Combat/Install Canonical Enemy Components` 用于统一检查和补齐敌人预制体的运行时骨架。

## 当前下一关规则

流程顺序现在保存在 `Assets/Resources/Progression/DefaultProgressionSettings.asset`。这个 SO 的 `_nodes` 列表中，上一个节点的下一个元素就是下一关。通关后系统读取下一个节点的 `ScenePath` 加载场景，场景里的 `LevelRuntimeRoot` 再使用自己绑定的关卡 SO。

新增关卡需要创建关卡 SO、创建场景、拖入 `LevelRuntimeRoot` 并绑定关卡 SO，最后在 `DefaultProgressionSettings.asset` 的 `_nodes` 列表添加流程节点，不需要修改 C#。

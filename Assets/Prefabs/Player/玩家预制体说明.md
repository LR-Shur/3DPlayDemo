# Ellen 玩家预制体说明

## 推荐层级

```text
Player_Ellen                    逻辑根：碰撞、输入、状态机、移动
├─ PlayerVisualRoot             表现根：换皮、整体模型偏移、特效挂点
│  └─ TPOSS                     模型根：Animator、Animancer、动画位移桥接
│     ├─ Avatar.../Bip001       实际蒙皮骨架，生成原地动画时冻结其水平根曲线
│     └─ Bip002                 FBX 内另一套骨架，不用于当前模型蒙皮
└─ PlayerCameraTarget           摄像机跟随与观察目标
```

## 位移规则

- 原始 FBX 保留为源资产，`EllenAnimationCatalogGenerator` 会为全部运行时动画生成可写的原地 `.anim` 副本。
- 原地副本将 `Bip001` 的 X/Z 曲线统一固定为骨架绑定原点 `0`；不能保留各动画的首帧值，否则不同动画的根位置会在缩放骨架上造成模型瞬移。腿、身体、尾巴、裙子、武器等其余动画曲线全部保留。
- Idle、Walk、Run、攻击等动画目录条目引用原地副本，由代码或状态机控制逻辑根。
- 翻滚使用动画目录中的 `AuthoredMotionDistance` 和归一化位移曲线，按动画实际进度推进逻辑根。
- 前翻滚默认 2.8 米，后撤翻滚默认 2.2 米；改变帧率不会改变动作总距离。
- `PlayerAnimationMotionBridge` 只为未来真正可用的 Root Motion 动画读取 `Animator.deltaPosition`，当前 Ellen 翻滚不依赖这个 FBX 的无效根运动输出。
- `PlayerMotor` 最终通过 `CharacterController.Move` 移动逻辑根，碰撞体、相机目标和模型会一起移动。
- `PlayerInputReader` 会从输入资源 JSON 创建每个玩家独占的运行时副本，多个预制体实例不会共享动作启用状态。
- 不允许任何脚本读取 TPOSS 的局部位置来推算位移，也不允许每帧把 TPOSS 拉回原点。

## 调整位置

- 普通移动速度：`PlayerConfig`。
- 每个动画的位移策略、翻滚总距离和位移曲线：`EllenAnimationCatalog`。
- 模型整体位置或朝向偏差：只调整 `PlayerVisualRoot`，不要调整 `Bip001`。
- 动画导入规则：Unity 菜单 `Train/Animation/同步 Ellen Root Motion 导入设置`。
- 重新生成运行时动画与目录：Unity 菜单 `Train/Player/重新生成 Ellen 动画目录`。
- 原地动画运行验证：Unity 菜单 `Train/Player/验证 Ellen 玩家预制体运行结构`。
- 翻滚位移运行验证：Unity 菜单 `Train/Player/验证 Ellen 翻滚位移`。
- 动画状态映射与输入阶段说明：`玩家动画状态映射.md`。
- 完整性校验：Unity 菜单 `Train/Player/验证 Ellen 动画状态映射`。

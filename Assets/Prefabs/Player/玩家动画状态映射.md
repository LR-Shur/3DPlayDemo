# Ellen 动画状态映射

`EllenAnimationCatalog` 已完整收录 75 条动画。每一条都有稳定的 `PlayerAnimationId`、播放规则、位移策略和 `PlayerAnimationStateKind`，玩法代码不再直接依赖 FBX 文件名。

## 本次补齐的移动状态

```text
Idle
 ├─ 有移动输入 → Walk_Start → Walk
 ├─ 按住 Sprint → Run
 ├─ 松开移动键：Walk_End / Run_End → Idle
 └─ 输入方向与当前前方夹角过大 → TurnBack → Walk / Run

任意可行动状态
 └─ Left Ctrl → Evade_Front / Evade_Back
    ├─ 0%~65%：位移和动作不可打断
    └─ 65%~100%：若按下移动键，立即切回 Walk / Run；翻滚位移曲线在 65% 后保持为零
```

`Walk_Start` 使用脚本移动；`Walk`、`Run` 使用脚本移动；`Walk_End`、`Run_End`、`TurnBack` 只播放动作和重力。这样不会让停止或转身动画再次把角色向前推走。

起步和停步过渡会持续监听最新输入：松开 W 时 `Walk_Start` 会立刻切到 `Walk_Start_End`；在任意停步动画期间重新按下移动键会直接进入 `Walk` 或 `Run`。因此短按、松开、再按不会再卡在上一段过渡动作中。

## 当前可直接测试的操作

| 输入 | 行为 | 使用的动画 |
| --- | --- | --- |
| 鼠标左键 | 基础普攻连段；连续按至第五段 | `Attack_Normal_01_01`、`01_02`、`02_01`、`02_02` 和第三套终结技 |
| 第五段时方向输入 | 选择普通攻击第三套的前、后、近身变体 | 全部 `Attack_Normal_03_*` 变体；按住 Shift 选择第二套 `03_02` 变体 |
| 数字 `1` | 四段分支攻击主链；按住后退输入使用 Short 起手 | `Attack_Branch_01~04`、`Attack_Branch_04_End`；Short/早期 End 为条件分支或提前收招 |
| 数字 `2` | 突击攻击链 | `Attack_AssaultAid` 的方向变体和 `End` |
| `Shift + 鼠标左键` | 冲刺斩击链 | `Attack_Dash_Start`、`Loop`、`Slash`、`Cut`、`Cut_End`、`End` |
| `F` | 突进攻击 | `Attack_Rush`、`Attack_Rush_End` |
| `C` | 格挡动作；后退输入时直接测试反击 | 格挡使用 `Attack_ParryAid_*`；后退使用 `Attack_Counter`、`End` |
| `Left Ctrl` | 前/后翻滚 | `Evade_Front`、`Evade_Back` |
| 长按 `E` | 任务交互演示 | `QuestStart` |
| `Space` | 真实跳跃物理 | 当前没有导入的 Jump 动画，因此不会错误复用翻滚或攻击动画 |

冲刺、突进和突击的位移不读取 FBX Root Motion，而是由目录中的 `Authored Motion Distance` 和曲线驱动 `CharacterController`。这些距离可以在 `EllenAnimationCatalog` 中逐段微调。

## 动画与状态类别

| 状态类别 | 已收录动画 | 进入方式 |
| --- | --- | --- |
| `LocomotionIdle` | `Idle`、`Idle_AFK` | 移动子状态机 |
| `LocomotionStart` | `Walk_Start` | 有移动输入时从 Idle 起步 |
| `LocomotionLoop` | `Walk`、`Run` | 移动子状态机循环播放 |
| `LocomotionStop` | `Walk_Start_End`、`Walk_End`、`Run_End` | 起步取消或松开移动键 |
| `LocomotionTurn` | `TurnBack` | 方向与人物当前前方明显相反 |
| `Dodge` | `Evade_Front`、`Evade_Back` | `Left Ctrl`；前后由输入方向决定 |
| `PrimaryAttack` | `Attack_Normal_01_01`、`Attack_Normal_01_02`、`Attack_Normal_02_01`、`Attack_Normal_02_02` | 攻击键；重复按键形成四段基础连段 |
| `CombatAction` | 其余全部 `Attack_*`（普通三段延伸、分支、突击辅助、反击、冲刺、突进、格挡辅助及其 End/Loop/Start 变体） | 战斗系统调用 `PlayerController.TryPlayAction` |
| `Reaction` | `Hit_L_Front`、`Hit_L_Back`、`Hit_H_Front`、`Hit_H_Back`、`HitFly_Front`、`HitFly_Back` | 受击系统调用 `TryPlayReaction` |
| `Death` | `Death` | 死亡系统调用 `TryPlayDeath`；不会自动回到移动 |
| `Transition` | `SwitchIn_Normal`、`SwitchOut_Normal`、`SwitchIn_Attack`、`SwitchIn_Attack_End`、`SwitchIn_Attack_Ex_Start`、`SwitchIn_Attack_Ex`、`SwitchIn_Attack_Ex_End` | 切人系统调用 `TryPlayTransition` |
| `Interaction` | `QuestStart` | 任务系统调用 `TryPlayInteractionOrCinematic` |
| `Cinematic` | `LevelSwitch` | 关卡/剧情系统调用 `TryPlayInteractionOrCinematic` |

## 可调参数

在 `Assets/Resources/Player/EllenAnimationCatalog.asset` 的每个定义中调整：

- `Movement Policy`：决定由脚本、Animator Root Motion，还是动画作者给出的曲线控制位移。
- `Authored Motion Distance`：翻滚等动作的总逻辑距离。
- `Authored Motion Curve`：归一化时间到归一化距离的曲线；翻滚曲线在 0.65 后应保持水平。
- `Movement Cancel Start Normalized Time`：允许移动输入抢回控制权的时间点。当前两个翻滚均为 `0.65`。
- `State Kind`：动画所属状态类别。它由目录生成器自动填写，通常无需手工改动。

## 检查方式

重新生成后，在 Unity 菜单执行 `Train/Player/验证 Ellen 动画状态映射`。控制台应输出“校验通过：共 75 条动画”，并列出每种状态类别的数量。
